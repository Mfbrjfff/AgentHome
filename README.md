# AgentHome
AgentHome — a fully local and self-evolving AI home agent on Raspberry Pi 5 powered by `bonsai-2:4b` and Whisper voice control, managing Philips Hue, Spotify, Roidmi vacuum, Withings scale, and Google Home via an iOS "Liquid Glass" style dashboard, with the ability to autonomously write, modify, and execute its own code.
